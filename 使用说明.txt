42天阅读打卡 · 桌面应用版

普通使用：直接下载附件「42天阅读打卡.html」，在手机浏览器里打开即可，无须联网。打卡记录保存在当前浏览器。

希望像App一样固定在主屏幕：
1. 将此压缩包解压后的 index.html、manifest.webmanifest、sw.js、两个图标文件上传到同一 HTTPS 网站目录（例如 GitHub Pages 静态网站）。
2. 在安卓手机的 Chrome 浏览器打开该 HTTPS 网址。
3. 点击右上角菜单 > 添加到主屏幕 / 安装应用（实际菜单名称随浏览器版本变化）。
4. 安装完成后可从桌面图标打开，首次打开需联网，随后支持离线使用。

注意：直接在浏览器中打开手机本地 HTML 文件时，很多浏览器不会显示「添加到主屏幕」。这是浏览器的限制，并非页面故障。单独的 HTML 附件不能自动安装到你的手机桌面。

数据存放在当前浏览器/网站的本地存储空间；不同网址之间不共享。可以使用页面底部的「备份、恢复打卡记录」进行迁移，也建议定期导出备份。
